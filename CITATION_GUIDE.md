# Citation and Version Identification

If this source supports a scholarly result, identify the exact implementation by referencing:

- Repository: **ASTSMC-AMR — Adaptive Super-Twisting Sliding Mode Control for a Six-Wheel Autonomous Mobile Robot**.
- Immutable code revision: full Git commit SHA used for the results.
- MATLAB release and experiment configuration.
- Manuscript citation, **once accepted/published and its bibliographic details are confirmed**.

A journal citation, DOI, publication date and definitive author list have **not been assigned in this file**. Do not fabricate them.

## Anonymous peer review

Do not insert author names, identifying affiliations or an identifying GitHub owner link into double-blind materials when the venue forbids it. Use an approved anonymized artifact and cite it as anonymized supplementary code according to venue instructions. Preserve a private record of the original repository and commit for final publication.

## After acceptance

Once all rights holders and coauthors approve public metadata, add a valid `CITATION.cff` file containing the authoritative manuscript title, authors, year and (if available) DOI; tag an immutable code release; and update the data release link. This repository deliberately does not publish placeholder author metadata as though it were final.
